# stillwater

A new Flutter project.

## Getting Started

This project was scaffolded manually. To generate the native platform
folders (android, ios, web, macos, etc.) and fetch dependencies, run the
following from inside the project directory:

```bash
cd ~/Desktop/stillwater
flutter create .
flutter pub get
flutter run
```

`flutter create .` fills in the platform runner code without overwriting
`lib/`, `pubspec.yaml`, or your tests.
